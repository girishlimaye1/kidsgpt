# KIDSGPT

KIDSGPT is a GitHub Pages-ready class gallery for kid-built AI-assisted projects.

## First Class Project

Students build a "Which One Are You?" personality quiz as a single HTML file.

Suggested student project path:

```text
quizzes/student-nickname/index.html
```

Use nicknames only. Do not publish full names, faces, school names, library location, or private details.

## Local Preview

Open `index.html` in a browser, or run a small local server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Publish With GitHub Pages

1. Create a GitHub repository named `kidsgpt`.
2. Push this folder to the repository.
3. In GitHub, go to Settings -> Pages.
4. Set source to the `main` branch and root folder.
5. Visit the Pages URL once GitHub finishes deploying.

## Adding Student Quizzes

1. Make a new folder under `quizzes/`.
2. Put the student's `index.html` inside it.
3. Add a card for the quiz in `index.html`.
4. Review the privacy and kindness checklist before publishing.

## Publishing Checklist

- No full names
- No photos of kids
- No school/library location
- No private contact info
- No mean quiz results
- No copyrighted logos or official images
- Student and parent are comfortable sharing
